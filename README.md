# QDelta Agency

> Turning Ideas Into Digital Experiences. Clear, engaging, and built to perform.

QDelta is a boutique digital agency crafting next-generation digital flagships, high-performance web applications, bespoke design systems, and autonomous digital experiences.

---

## 🚀 Tech Stack

- **Framework:** [Next.js 16 (Turbopack)](https://nextjs.org/)
- **UI & Components:** React 19, Tailwind CSS v4, Lucide Icons
- **Motion & 3D:** Motion (Framer Motion), Three.js, React Three Fiber & Drei
- **Typography:** Playfair Display, Inter, JetBrains Mono
- **Deployment:** Vercel Edge Network

---

## 🛠️ Getting Started

First, install dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
